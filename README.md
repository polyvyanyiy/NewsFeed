Приложение Новостной Ленты Autodoc с возможностью сохранения публикаций в локальную базу данных.

- UIKit без Storyboard.
- MVVM + Combine.
- UICollectionView + CompositionalLayout + DiffableDataSource.
- Пагинация.
- Async / Await.
- Оптимизация для iPad.
- Без сторонних библиотек.
- Локальная база данных: CoreData (программная инициализация).
- Поддержка ОС: iOS 16.0+.

Ключевые фичи и архитектурные решения:

1. Безопасная многопоточность
2. Бесшовная пагинация: Дозагрузка данных пачками по 15 элементов при приближении скролла к концу списка.
3. Разработан собственный асинхронный ImageLoader на базе системного NSCache. Кэш сохраняет обложки новостей в оперативной памяти приложения и не сбрасывается при сворачивании. 
4. Динамическая смена сетки (1х1, 2х2, 3х3)
5. Полноценный оффлайн-модуль «Избранное» (CoreData)
6. Адаптивное масштабирование UI-элементов (iPhone / iPad)
7. Адаптивный и тактильный дизайн (UI/UX)
- Эффект нажатия на ячейку: При нажатии на карточку она упруго и плавно уменьшается в масштабе.
- Интеграция с WebKit: По нажатию на новость навигационный контроллер открывает полноценный WKWebView по ссылке fullUrl. Верхняя граница браузера жестко привязана к safeAreaLayoutGuide, что исключает зарезание шапки сайта под системный бар iOS.
8. Оптимизация под iPad
- Приложение поддерживает все пространственные ориентации экрана на iPad (поворот не блокируется).
